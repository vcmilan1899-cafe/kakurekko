# かくれっこ ずかん

家の中にQRコードを隠して、見つけたキャラクターを図鑑に集めるWebアプリです。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（さがす・ずかん・おうちのひと） |
| `manifest.json` | ホーム画面に追加したときの設定 |
| `icon.svg` | アイコン |

## GitHub Pages で公開する手順

1. https://github.com にログインします（アカウントがなければ作成します）。
2. 右上の「＋」→「New repository」を押します。
   - Repository name: `kakurekko`（好きな名前でOK）
   - **Public** を選んで「Create repository」を押します。
3. 作ったリポジトリの画面で「uploading an existing file」を押し、
   `index.html`・`manifest.json`・`icon.svg` の3つをドラッグして「Commit changes」を押します。
4. 「Settings」→ 左メニューの「Pages」を開きます。
   - Source: **Deploy from a branch**
   - Branch: **main** / **/(root)** を選んで「Save」を押します。
5. 1〜2分待つと、`https://<ユーザー名>.github.io/kakurekko/` で開けるようになります。

> GitHub Pages で公開すると、URLを知っている人は誰でも開けます。ただし図鑑の記録は各スマホの中にだけ保存されるので、他の人に見られることはありません。

## あそびかた

1. **Android の Chrome** で上のURLを開きます。メニューの「ホーム画面に追加」をしておくとアプリのように使えます。
2. 「おうちのひと」タブで足し算に答えてメニューを開き、「印刷する」を押します。
   QRコードは**必ず GitHub Pages のURLで開いた状態で**印刷してください（QRの中にそのページのURLが入ります）。
3. 印刷したQRを切り取って、家のあちこちに隠します。
4. 子どもは「さがす」→「カメラで さがす」でQRを読み込みます。Android 標準のカメラアプリで読んでも登録されます。
5. 「おうちのひと」メニューでは、ヒントの入力や図鑑のリセット（もう一度遊ぶ）ができます。
